# LumaGlass 0.2.8

Minecraft 1.20.1 / Forge 47.4.22 / Java 17 · Sunny5349

## 更新

- 修复创造背包替换玻璃底板后，摧毁物品槽位没有图标的问题。槽位现在单独绘制带阴影的垃圾桶标记，保留原版摧毁行为与提示。
- 默认模糊强度改为 15%（半径 4.8）；折射 24、磨砂 100%、表面色调 0%，泛光关闭。工作室重置同步使用这些默认值。
- 保留箱子连续分区及其他模组复用原版 UI 的默认自动适配，README 与 API 文档同步更新。

## 升级

替换旧 JAR，只保留 `lumaglass-0.2.8.jar`。已有配置会保留，点击工作室“重置”，再点“完成”即可应用新默认值。

作者为 Sunny5349，游戏 Mod 页面描述留空。`-sources.jar` 供开发使用。
