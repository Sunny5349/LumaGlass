# LumaGlass 0.2.9

Minecraft 1.20.1 / Forge 47.4.22 / Java 17 · Sunny5349

## 更新

- 配方书主体、分类与配方条目改为完整玻璃底板，移除原贴图暗色内框。书本开关、搜索与筛选图标独立绘制，保留原版操作。
- 成就通知弹窗移除黑色底板，保留标题、文字与物品图标。
- 按 L 打开的进度页面保持原版，不再套用自动玻璃主题。
- 增加 JEI 15 可选适配，覆盖合成窗口、配方面板、分类、搜索与控件底板；保留物品、配方箭头和机器示意图。受 `otherModUi` 开关控制，无需额外依赖或桥接模组。
- 单人和多人列表取消整页玻璃叠层，背景改用纯黑透明遮罩调暗，去掉额外灰白底色。
- README、API 文档与独立接入示例同步到 0.2.9，公开 API 保持兼容。

## 升级

替换旧 JAR，只保留 `lumaglass-0.2.9.jar`。已有配置保留；本次修复直接生效，不需要删除配置或世界。JEI 适配需要启用 `vanillaUi` 和 `otherModUi`。泛光仍默认关闭。

作者为 Sunny5349，游戏 Mod 页面描述留空。`-sources.jar` 供开发使用。

## 验证

离线构建、API 示例编译及 23 个发行 Mixin 映射检查通过。最终发行 JAR 在纯 Forge，以及 JEI 15.21.0.148 + Embeddium 0.3.31 + Oculus 1.8.0（未启用光影包）两组正式客户端中各通过 52 个场景。新增配方书、成就通知、原版进度页面与底板像素检查；JEI 环境额外打开实际合成查询窗口，检查主题开关并验证可选底板绘制器。已检查实际截图。
