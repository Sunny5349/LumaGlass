# LumaGlass 0.2.5

Minecraft 1.20.1 / Forge 47.4.22 / Java 17 · Sunny5349

## 更新

- 创造物品栏分类底板改为完整圆角玻璃，移除未选中页签的暗色凹陷，保留原版图标与输入行为。
- 公共 API 新增每个面板独立泛光颜色：`GlassStyle.withGlowColor(0xRRGGBB)`；`withGlobalGlowColor()` 恢复继承全局颜色。
- 普通面板与贴图面板均支持独立颜色，仍尊重用户的泛光总开关和强度。
- 保留六参数 `GlassStyle` 构造方法和现有绘制方法。record 新增颜色组件，反射/序列化调用方应参考 README。
- README 包含完整接入教程、可编译示例、配置说明和构建命令。

## 验证范围

离线构建、13 个发行 Mixin 映射检查、本地 Maven 产物和独立 API 消费工程编译通过。导出的完整源码在独立目录中使用已有依赖缓存重新构建成功。

纯 Forge 以及下述渲染模组组合均通过 36 个场景。正式客户端 `forgeclient` 在 Java 17、Forge 47.4.22、Intel RaptorLake-S Mobile Graphics 上验证；Embeddium 0.3.31 + Oculus 1.8.0（未开启光影包）通过 36 个场景，包含：

- 原版页面、创造物品栏、滚轮和拖动、单人背景残留、多人页面、世界背包、窗口缩放与资源重载。
- API 生命周期和材质参数、画布背景隔离、同一 frame 的红/蓝独立颜色与全局颜色继承。
- 普通和贴图面板的像素检查，以及全局关闭泛光后所有颜色停止发光。
- 创造物品栏上/下、选中/未选中四种页签底板无旧暗色遮罩。

尚未验证完整第三方整合包、启用光影包、所有资源包、其他 GPU 或长期性能。适合发布为 0.2.5 测试版本并收集兼容性反馈，不作零缺陷保证。
